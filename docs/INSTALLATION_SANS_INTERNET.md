# Installer pédafiche sans Internet

Après la publication de la version (page **Releases** du dépôt), télécharger une seule fois :
- **PC Windows** : `PedaFiche-Installation.exe` — double-clic, puis icône « PedaFiche » sur le Bureau.
- **Téléphone / tablette Android** : `PedaFiche.apk` — l'ouvrir, autoriser « sources inconnues » si demandé.

Au premier lancement, créer le compte (nom, identifiant, mot de passe). Ensuite, tout fonctionne sans Internet ;
les données restent sur l'appareil (faire des sauvegardes régulières).
